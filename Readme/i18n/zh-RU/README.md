## Что такое TCMinerSystem?

TCMinerSystem — система проксирования майнинг-пулов и операционного управления для майнеров, майнинговых ферм и узлов пула. Она позволяет подключать оборудование к традиционным пулам, централизованно управлять портами переадресации и при необходимости развёртывать собственные узлы пула.

Сопутствующий локальный клиент безопасности [TMS](https://github.com/MinerProxyPro/TMS) обеспечивает шифрование и сжатие трафика, сокращает количество подключений через общедоступную сеть и расход полосы пропускания, а также повышает безопасность канала. Перед началом работы ознакомьтесь с [соглашением об использовании](https://tcminersystem.gitbook.io/tcminersystem/guan-yu/fu-wu-xie-yi).

## Основные возможности

| Возможность | Описание |
| --- | --- |
| Прокси традиционных пулов | Централизованное управление подключениями майнеров, портами переадресации и целевыми пулами упрощает массовое подключение оборудования и повседневную эксплуатацию. |
| Собственные узлы пула | Развёртывание собственных узлов пула для майнинговых ферм, операторов узлов и проектов с собственным хешрейтом. |
| Управление хешрейтом и комиссиями | Настройка статистики хешрейта, правил распределения и пользовательских комиссий с наблюдением за состоянием системы. |
| Защищённая передача TMS | Шифрование и сжатие трафика с помощью сопутствующего клиента снижает нагрузку на канал и ограничивает открытость соединения. |
| Развёртывание на разных платформах | Быстрое развёртывание и обновление с помощью исполняемых файлов для Linux и Windows и установщика для Linux. |
| Веб-панель управления | Просмотр оборудования, портов, хешрейта, журналов, версий и состояния системы в браузере. |

## Быстрый старт

> [!IMPORTANT]
> Имя администратора по умолчанию — `qzpm19kkx`, пароль по умолчанию — `xloqslz913`. Сразу после первого входа измените имя пользователя, пароль и порт веб-панели, а также ограничьте доступ к порту управления с помощью межсетевого экрана.

### Linux

Рекомендуется Ubuntu. Выполните следующую команду в терминале Bash, чтобы открыть меню установки:

```sh
bash <(curl -s -L https://github.com/mine-Proxy/TCMinerSystem/raw/main/install.sh)
```

Если GitHub медленно работает в вашем регионе, попробуйте альтернативный адрес установки:

```sh
bash <(curl -s -L https://cdn.tcminersystem.com/mine-proxy/TCMinerSystem/raw/main/install.sh)
```

После запуска установщика следуйте подсказкам меню для установки, обновления, запуска, остановки и настройки службы и портов.

<p align="center">
  <img src="../../../image/install.gif" alt="Меню установки TCMinerSystem в Linux" width="560">
</p>

### Windows

1. Откройте каталог [windows](https://github.com/mine-Proxy/TCMinerSystem/tree/main/windows) в репозитории.
2. Выберите новейший файл `tcstminersystem-*.exe`. Это имя исполняемого файла TCMinerSystem.
3. Откройте страницу файла и нажмите `View raw`, чтобы скачать его.
4. Запустите скачанную программу и следуйте подсказке терминала, чтобы открыть панель управления в браузере.
5. Сразу после первого входа измените имя пользователя, пароль и порт веб-панели.

## Прозрачное подключение в авторизованных сетях

Если вы управляете майнинговой фермой или получили явное разрешение на администрирование её маршрутизаторов и оборудования, обратитесь к команде проекта для оценки развёртывания на основе DNS или прозрачного прокси. Это может сократить объём индивидуальной перенастройки майнеров.

> [!WARNING]
> Прозрачное подключение допускается только в сетях, где владелец оборудования предоставил явное и осознанное разрешение. Не перехватывайте, не пересылайте и не перенаправляйте оборудование, хешрейт или сетевой трафик, которыми вы не владеете и которыми не уполномочены управлять.
